# vcv-rack-2-learn

Курс «Модульный синтез с нуля» внутри VCV Rack 2: 52 урока, 576 блоков. Уроки открываются прямо в стойке. Текст, схемы, вопросы и задания — модули плагина **Atlas**. Готовые патчи едут к нужному ряду. Проверка собранного патча работает без сети. **ИИ-репетитор** на Claude Code видит текущий блок и твой патч и отвечает по-русски.

## Что внутри

| Папка | Что это |
|---|---|
| `plugin/` | Плагин Atlas для VCV Rack 2 (C++): Навигатор, Страница, Подпись, Схема, Вопрос, Задание, Верстак, Репетитор, Памятка |
| `course/` | Уроки в YAML (`course/lessons/`), шаблоны блоков, токены оформления, калибровка ручек |
| `compiler/` | Компилятор: YAML → `plugin/res/course/pack.json` и патчи уроков; валидатор и проверки |
| `facts/` | База фактов курса: снимки модулей, файлы проверок, глоссарий, источники, проверенные цитаты |
| `server/` | Сервер репетитора: держит процесс `claude`, передаёт ему контекст блока и патча, хранит прогресс |
| `tutor/` | Системный промпт репетитора и заглушка `claude` для тестов |
| `scripts/` | Сборка, установка, автопроверка в Rack, служебные инструменты |
| `qa/` | Рендеры всех модулей и уроков для визуальной проверки |
| `docs/` | План, отчёт и журнал разработки, чек-лист ручной проверки |

## Что нужно

- macOS на Apple Silicon: сборка и установщик проверены только там.
- [VCV Rack 2 Free](https://vcvrack.com/Rack) 2.6. Плагины из VCV Library: **Fundamental**, **Impromptu Modular**, **Valley**, **VCV Recorder**, **Audible Instruments** и **VCV Rack MCP Server**. Через последний репетитор читает патч.
- Node.js 20+, Xcode Command Line Tools (`xcode-select --install`).
- [Claude Code](https://claude.com/claude-code) с выполненным входом: репетитор запускает `claude`.

## Установка

```bash
git clone https://github.com/nikrr4000/vcv-rack-2-learn.git
cd vcv-rack-2-learn
scripts/build.sh      # SDK и пакеты при первом запуске, проверка уроков, сборка плагина, тесты
scripts/install.sh    # плагин → папка плагинов Rack (старый Atlas уходит в atlas-backups)
npm start             # сервер репетитора на http://127.0.0.1:5175 — держи его открытым
```

Дальше закрой Rack полностью (⌘Q) и запусти снова. Добавь модуль **Atlas → Навигатор** и нажми «Продолжить».

Без сервера курс тоже проходится: текст, схемы, вопросы и проверки работают. Отвечать не будет только репетитор.

## Настройки сервера

Через переменные окружения или `state/settings.json`:

| Переменная | По умолчанию | Что задаёт |
|---|---|---|
| `PORT` | `5175` | порт сервера; плагин ищет его на этом адресе (меняется в меню Навигатора) |
| `TUTOR_MODEL` | `sonnet` | модель репетитора: `sonnet`, `opus`, `haiku` |
| `TUTOR_EFFORT` | `low` | усилие: `low`, `medium`, `high` |
| `RACK_TUTOR_CLAUDE` | найденный `claude` | путь к CLI Claude Code |
| `RACK_PORT` | `2600` | порт VCV Rack MCP Server |
| `NOTES_DIR` | `state/notes` | заметки уроков с «Журналом в Rack»; можно указать папку Obsidian |
| `STATE_DIR` | `state/` | прогресс, журнал репетитора, настройки |

## Разработка

```bash
npm test                                         # сервер, компилятор, 102 проверки шаблонов уроков
scripts/build.sh --test && node scripts/rack-test.mjs   # все уроки в отдельном экземпляре Rack
make -C plugin/tests client                      # плагин ↔ сервер репетитора, сквозной тест
```

Урок правится в `course/lessons/<id>.yaml`, затем `scripts/build.sh`. Правила текста — `course/templates/STYLE.md`.
