# Часть 2. Источники звука

- **Период и частота** (англ. period, frequency) — период — время одного повтора волны, частота — число повторов в секунду (f = 1/T); чем выше частота, тем выше нота. Урок 2.1.
- **Форма волны** (англ. waveform) — вид одного периода сигнала: синус, треугольник, пила, прямоугольник; от неё зависит тембр, а не высота. Урок 2.1.
- **Гармоники** (англ. harmonics) — составляющие звука с частотами, кратными основной; чем их больше, тем «ярче» звук. Урок 2.1.
- **Ширина импульса** (англ. pulse width) — доля периода, в которую прямоугольная волна «высокая»; 50 % — симметричный меандр. Урок 2.2.
- **PWM** (англ. pulse width modulation) — управление шириной импульса сигналом (чаще LFO); тембр прямоугольника «оживает». Урок 2.2.
- **LFO** (англ. low-frequency oscillator) — низкочастотный генератор управляющего сигнала; сам не звучит, а двигает параметры других модулей. Урок 2.2 (подробно 4.1).
- **Offset (Bipolar / Unipolar)** (англ. offset) — переключатель смещения LFO: Bipolar — колебания вокруг нуля, Unipolar — только положительные значения (по умолчанию в этой версии). Урок 2.2.
- **Жёсткая и мягкая синхронизация** (англ. hard sync, soft sync) — режимы, в которых ведомый осциллятор по фронту ведущего обрывает цикл (Hard) или разворачивает волну (Soft). Урок 2.2.
- **Ведущий и ведомый осциллятор** (англ. master, slave) — ведущий задаёт высоту и шлёт сигнал синхронизации, ведомый по нему перезапускает цикл и задаёт тембр. Урок 2.2.
- **Частотная модуляция, FM** (англ. frequency modulation) — управление частотой осциллятора другим сигналом; медленно — вибрато, на звуковой частоте — новые частоты и звонкий тембр. Урок 2.2.
- **Боковые полосы** (англ. sidebands) — новые частоты вокруг несущей, которые возникают при FM на звуковой скорости. Урок 2.2.
- **Интервал** (англ. interval) — отношение высот двух нот; октава — частота вдвое больше (+1 В на 1V/oct), квинта — семь полутонов. Урок 2.3.
- **Цент** (англ. cent) — сотая часть полутона; единица для маленьких расстроек. Урок 2.3.
- **Расстройка и биения** (англ. detune, beating) — небольшая разница частот двух осцилляторов вызывает пульсации громкости со скоростью, равной разнице в герцах. Урок 2.3.
- **Юнисон** (англ. unison) — несколько осцилляторов на одной ноте с лёгкой расстройкой: звук толще и «дышит». Урок 2.3.
- **Wavetable (таблица волн)** (англ. wavetable) — ряд одноцикловых волн, между которыми осциллятор плавно переходит. Урок 2.4.
- **Положение в таблице** (англ. wavetable position) — параметр, выбирающий, какую волну таблицы читает осциллятор; движение положения меняет тембр. Урок 2.4.
- **Шум** (англ. noise) — случайный сигнал без периода, а значит без ноты; источник для ветра, шипения и ударных. Урок 2.5.
- **Цвет шума** (англ. noise colour) — название шума по распределению энергии по частотам: белый, розовый, красный, фиолетовый, синий, серый, чёрный. Урок 2.5.
- **Спектральный наклон** (англ. spectral slope) — на сколько дБ на октаву меняется мощность шума с ростом частоты (белый 0, розовый −3, красный −6, синий +3, фиолетовый +6). Урок 2.5.
