# Часть 0. Среда и первый звук

- **Плагин** (англ. plugin) — пакет модулей одного автора; часть плагинов вшита в Rack, остальные берутся из VCV Library. Урок 0.1.
- **VCV Library** (англ. VCV Library) — каталог плагинов на vcvrack.com; подписка оформляется на сайте, установка идёт в Rack командой «Update all» и перезапуском. Урок 0.1.
- **Учётная запись VCV** (англ. VCV account) — аккаунт на vcvrack.com, к которому привязаны подписки на плагины. Урок 0.1.
- **Шкаф** (англ. rack) — рабочее поле Rack: ряды, на которые ставятся модули. Урок 0.2.
- **HP** (англ. horizontal pitch) — единица ширины панели модуля; в Eurorack 1 HP равен 5,08 мм. Урок 0.2.
- **Браузер модулей** (англ. module browser) — окно поиска и добавления модулей, открывается клавишей Enter над пустым местом шкафа. Урок 0.2.
- **Кабель** (англ. cable) — соединение от выхода одного модуля ко входу другого; из одного выхода можно вести несколько кабелей. Урок 0.2.
- **Автосохранение** (англ. autosave) — периодическая запись текущего патча Rack в папку пользователя; не заменяет сохранения под своим именем. Урок 0.2.
- **Пресет** (англ. preset) — сохранённые положения ручек одного модуля. Урок 0.2.
- **Аудиоинтерфейс (Audio)** (англ. Audio module) — модуль Core, который связывает Rack со звуковым устройством компьютера: Audio 2, Audio 8, Audio 16. Урок 0.3.
- **Частота дискретизации** (англ. sample rate) — сколько раз в секунду Rack считает значение сигнала; привычные значения 44100 и 48000 Гц. Урок 0.3.
- **Размер блока** (англ. block size) — сколько отсчётов Rack отдаёт звуковому устройству за один раз; больше блок — надёжнее и больше задержка. Урок 0.3.
- **Безопасная громкость** (англ. safe volume) — порядок включения: системная громкость вниз, Level около 0 дБ, наушники сняты до проверки, поднимать медленно. Урок 0.3.
- **MCP-сервер** (англ. MCP server) — модуль MCP Server (плагин Neural Harmonics), через который агент читает патч и вносит правки по протоколу MCP. Урок 0.4.
- **Порт** (англ. port, HTTP port) — номер сетевого порта, на котором слушает сервер; для курса 2600. Не путать с разъёмом модуля. Урок 0.4.
- **Ограничения агента** (англ. agent limits) — через MCP Server нельзя сохранить или загрузить патч и настроить модуль Audio; по правилам курса агент меняет только свои модули. Урок 0.4.
