# 8.3 Хэты

## Зачем

После урока у ученика третий инструмент ритм-секции: хэт из шума и фильтра верхних частот, который умеет быть и закрытым (короткий «цик»), и открытым (длинный «шшш»), и обрывается следующим ударом, как на настоящей установке. Файл `vcv-8.3.vcv` пойдёт в часть 9: в уроке 9.2 хэты встанут поверх бочки и малого барабана.

## Пробник

1. Вопрос: чем в нашем патче закрытый хэт отличается от открытого?
   - Верно: длиной хвоста огибающей; тембр шума и фильтр те же.
   - Неверно: открытый хэт берёт другой цвет шума. Заблуждение: тембр определяет сам источник.
   - Неверно: у открытого хэта громче Level у VCA-1. Заблуждение: открытый — это более громкий.
2. Вопрос: зачем после Noise стоит фильтр верхних частот?
   - Верно: чтобы убрать низ и оставить тонкое шипение: хэт — это самый верхний звук ударной установки.
   - Неверно: чтобы убрать звук из левого канала. Заблуждение: фильтр отвечает за стерео.
   - Неверно: чтобы шум стал тише. Заблуждение: фильтр верхних частот — регулятор громкости.
3. Вопрос: что должно случиться с хвостом открытого хэта, если сразу следом прозвучит закрытый?
   - Верно: хвост обрывается: следующий удар перезапускает огибающую с коротким Decay.
   - Неверно: хвост допевает до конца поверх нового удара. Заблуждение: каждый удар живёт сам по себе.
   - Неверно: хвост обрывает Release у VCA-1. Заблуждение: у VCA-1 есть своя огибающая.

## Понятие

Идея без модулей. Хэт — две металлические тарелки на стойке: при ударе их колебания хаотичны, без чётких гармоник, это почти шум. Если тарелки сжаты педалью, звук коротковатый и сухой (закрытый хэт); если приоткрыты, он звенит и затухает долго (открытый). Ударишь закрытым после открытого — открытый обрывается: это и есть «чок» (от англ. choke, зажим). Источников у этого урока мало, и они говорят о другом. [ne-hats](https://noiseengineering.us/blogs/loquelic-literitas-the-blog/creating-fm-hats/) строит хэт из двух неточно настроенных осцилляторов с частотной модуляцией, крутым фильтром верхних частот и коротким VCA; открытый хэт получается длинным Decay, закрытый — коротким, и автор мирится с тем, что строй тут не важен: "we'll throw tuning and harmonic relationships to the wind" ([ne-hats](https://noiseengineering.us/blogs/loquelic-literitas-the-blog/creating-fm-hats/)). [sos-38](https://www.soundonsound.com/techniques/synthesizing-realistic-cymbals) делает тарелку из FM прямоугольных волн (полосовой «звон» плюс верхний хвост) и коротко упоминает закрытый и открытый хэт. [sos-39](https://www.soundonsound.com/techniques/practical-cymbal-synthesis) разбирает схему TR-808: "six square-wave oscillators tuned enharmonically" ([sos-39](https://www.soundonsound.com/techniques/practical-cymbal-synthesis)); автор сам приходит к выводу, что на модульной системе лучше работают пары модулированных осцилляторов.

Что здесь принадлежит курсу, а не экспертам. Мы берём не FM-хэт, а упрощённый вариант: белый шум через фильтр верхних частот. Он проще и укладывается в четыре модуля урока; FM-хэт можно построить позже из двух VCO (вариант для самостоятельного эксперимента). Выбор между закрытым и открытым хэтом и обрыв хвоста: это собственный приём курса, у экспертов по нему мало материала. Приём такой: на оба хэта один ADSR; у каждого шага секвенсора своё напряжение CV 2, которое удлиняет Decay и Release (ноль вольт для закрытого, около трёх для открытого). Любой следующий триггер заставляет огибающую начаться заново: так «чок» получается сам, без отдельной логики.

Что показать (агент рисует): одна горизонтальная ось, несколько ударов подряд; на закрытых коротенькие пики, на открытом длинный пик, который обрывается следующим ударом.

## Анатомия

Карточки: `Fundamental.Noise.md`, `Fundamental.VCF.md`, `Fundamental.ADSR.md`, `Fundamental.VCA-1.md`, для источника ритма `Fundamental.SEQ3.md` (из 5.2). Не больше трёх терминов на шаг:

1. Noise: выход White noise. Для хэта можно взять и Violet noise: у него энергия смещена в верх, звук тоньше; сравним в «Покрути сам». Ручек нет.
2. VCF как фильтр верхних частот: вход Audio, выход Highpass filter; Cutoff frequency высоко (4000…8000 Гц), Resonance небольшой (0…20%). Чем выше срез, тем тоньше хэт. Остальные ручки и входы VCF (Cutoff frequency CV, Drive и его CV, Resonance CV, входы Frequency, Resonance, Drive) пока не нужны. Термин: длина хвоста.
3. ADSR: Attack (минимум), Decay и Release (равные, по причине из 8.1), Sustain (ноль). Входы Decay и Release принимают CV; ручки Decay CV и Release CV (в процентах) задают, сколько этого CV доходит до времени. Термин: закрытый и открытый хэт.
4. VCA-1: вход Channel (шум после фильтра), вход CV (огибающая), Level (около 60%), Response mode (Linear или Exponential, хэту подходит Exponential).
5. SEQ 3: выход Trigger (удары), выход CV 2 (напряжение на шаге: ноль для закрытого, три вольта для открытого). Термин: чок (хвост обрывается следующим ударом).

## Демо

Агент строит хэты в своём ряду; ученик смотрит. Перед первым звуком напомнить убавить громкость.

Модули: Fundamental/SEQ3, Fundamental/Noise, Fundamental/VCF, Fundamental/ADSR, Fundamental/VCA-1, Fundamental/Scope; звук идёт в Audio ученика.

Кабели:

1. Noise `White noise` → VCF `Audio`.
2. VCF `Highpass filter` → VCA-1 `Channel`.
3. ADSR `Envelope` → VCA-1 `CV`.
4. SEQ 3 `Trigger` → ADSR `Gate`.
5. SEQ 3 `CV 2` → ADSR `Decay`.
6. SEQ 3 `CV 2` → ADSR `Release`.
7. VCA-1 `Channel` → `To "device output 1"` и `To "device output 2"` (Audio ученика).
8. ADSR `Envelope` → Scope `Ch 1`.

Параметры (displayValue):

| Модуль | Параметр | Цель |
| --- | --- | --- |
| SEQ 3 | Tempo | 480 (по шагу на шестнадцатую при 120 bpm) |
| SEQ 3 | Step 1…8 trigger | 1 (все); Run не трогать |
| SEQ 3 | CV 2 step 1, 2, 3, 5, 6, 7 | 0 (по умолчанию) |
| SEQ 3 | CV 2 step 4, 8 | 3 |
| ADSR | Attack / Decay / Sustain / Release | 2 / 40 / 0 / 40 |
| ADSR | Decay CV, Release CV | 60 |
| VCF | Cutoff frequency / Resonance | 6000 / 0 |
| VCA-1 | Level / Response mode | 60 / Exponential |
| Scope | Time | 200 |

Порядок демо: сначала кабели 1–4 без кабелей 5 и 6: все хэты одинаково короткие (Decay 40 мс). Потом кабели 5 и 6: на шагах 4 и 8 хвост удлиняется. Агент читает `Envelope` на этих шагах и на соседних и сообщает ученику, в какое время она падает. Как именно вход CV влияет на время (масштаб при 60%), агент выясняет по Scope и при необходимости меняет Decay CV и Release CV, пока открытый хэт не станет в несколько раз длиннее закрытого; точные числа не обещать. Затем ученик слышит, что открытый хэт обрывается следующим: показать на Scope, что на шагах 5–8 огибающая начинается заново, не доходя до нуля. В конце агент удаляет свои модули и кабели.

## Покрути сам

1. Cutoff frequency у VCF от 2000 до 8000 Гц: хэт от плотного «чика» к тонкому шипению; на Scope форма огибающей та же.
2. Decay и Release у ADSR вместе от 20 до 80 мс: закрытые хэты суше или мягче; открытые тоже меняются, потому что CV только добавляется.
3. Decay CV и Release CV от 20 до 100%: открытый хэт тянется длиннее; закрытые не меняются, потому что на их шагах CV 2 равен нулю.
4. CV 2 step 4: от 0 до 5 В: этот шаг становится открытым; на Scope хвост длиннее.
5. Выход Violet noise вместо White noise (кабель Noise переставить): хэт тоньше и холоднее.
6. Resonance у VCF от 0 до 30%: появляется «звон» у среза, хэт металличнее.

## Звук-референс

- «ярче», «тоньше», «воздух»: Cutoff frequency вверх (6000…8000 Гц) или выход Violet noise.
- «глуше», «толще», «в лоб»: Cutoff frequency вниз (3000…4000 Гц), Level вверх.
- «короче», «суше», «закрытый короче»: Decay и Release вместе вниз.
- «открытый длиннее», «шипит дольше»: Decay CV и Release CV вверх или CV 2 на шаге выше.
- «открытый звучит как закрытый»: у шага CV 2 ноль, или Decay CV и Release CV у нуля.
- «металлический», «звенит»: Resonance у VCF вверх (15…30%).
- «закрытый обрывается слишком резко»: Release вверх.
- «громко», «режет»: Level у VCA-1 вниз.

## Практикум

Ученик собирает хэты сам, агент ничего не трогает: Noise White noise → VCF Highpass filter → VCA-1 с ADSR на CV; SEQ 3 запускает ADSR через Gate; CV 2 идёт в Decay и в Release у ADSR; на шагах CV 2 разный (ноль и около трёх вольт); Decay CV и Release CV подняты; звук в Audio. Условия: Cutoff frequency не ниже 4000 Гц, Sustain не выше 10%, Decay CV и Release CV не ниже 30%. Паттерн ученик выбирает сам: где закрытые, где открытые. Подсказки только через результат проверки.

## Проверка

Файл `checks/p8-03-hihats.json`. Что проверяет: семь кабелей (Noise `White noise` → VCF `Audio`; VCF `Highpass filter` → VCA-1 `Channel`; ADSR `Envelope` → VCA-1 `CV`; SEQ 3 `Trigger` → ADSR `Gate`; SEQ 3 `CV 2` → ADSR `Decay`; SEQ 3 `CV 2` → ADSR `Release`; VCA-1 `Channel` → `To "device output 1"`); Cutoff frequency не ниже 4000 Гц, Sustain не выше 10%, Decay CV и Release CV не ниже 30%; на `Envelope` напряжение выше 1 В; на `CV 2` у SEQ 3 размах больше 1 В (значит, у шагов разные значения: есть и закрытые, и открытые). Сам `Trigger` не проверяется: импульс в 1 мс пробой не ловит.

Лесенка подсказок (вопрос, место, ответ):

- Кабель 1: «Откуда берётся шум?» → «Noise» → «White noise в Audio у VCF».
- Кабель 2: «Какой фильтр нужен хэту?» → «Выходы VCF» → «Highpass filter в Channel у VCA-1».
- Кабель 3: «Что управляет громкостью по времени?» → «ADSR» → «Envelope в CV у VCA-1».
- Кабель 4: «Что запускает огибающую?» → «SEQ 3» → «Trigger в Gate у ADSR».
- Кабели 5–6: «Чем различаются закрытый и открытый?» → «CV 2 у SEQ 3» → «CV 2 и в Decay, и в Release у ADSR».
- Cutoff frequency ниже 4000: «Остался ли в шуме низ?» → «VCF» → «подними».
- Decay CV или Release CV почти ноль: «Влияет ли CV 2 на длину хвоста?» → «ручки CV у ADSR» → «подними хотя бы до 30%».
- `CV 2` стоит: «Разные ли ручки CV 2 step?» → «SEQ 3» → «ноль для закрытого, около 3 В для открытого».
- Огибающая стоит: «Идёт ли секвенсор и горят ли кнопки триггеров?» → «SEQ 3» → «включи кнопки; Run переключает ход, не нажимай вслепую».

## Слом

В демо-патче агента (хэты играют, шаги 4 и 8 открытые): снять кабель SEQ 3 `CV 2` → ADSR `Release`. Ученик находит на слух и на Scope: открытые хэты стали короткими: у `Envelope` хвост на шагах 4 и 8 почти не длиннее, чем на остальных. Ответ: на коротком триггере хвост ведёт Release, а не Decay; CV должен идти в оба входа. Агент возвращает кабель и удаляет демо.
