# 5.1 Такт и темп

## Зачем

После урока ученик умеет задать темп в ударах в минуту (BPM), выдать из одного главного такта несколько сигналов разной частоты и вернуть всё на начало сбросом. Это «метроном» будущего трека: в частях 8–9 от одного такта будут тактироваться бас, ритм-секция и лид.

## Пробник

1. Вопрос: темп 120 BPM. Сколько долей проходит за секунду?
   - Верно: две (120 в минуту, 60 секунд в минуте).
   - Неверно: сто двадцать. Заблуждение: BPM и герцы — одна и та же единица без пересчёта.
   - Неверно: полдоли. Заблуждение: путают частоту с периодом (0,5 с — это длительность одной доли, а не их число).
2. Вопрос: что делает сигнал Reset у секвенсера?
   - Верно: возвращает его на первый шаг, а темп не трогает.
   - Неверно: останавливает секвенсер. Заблуждение: Reset и Run — одно и то же.
   - Неверно: возвращает ручку темпа в исходное положение. Заблуждение: Reset сбрасывает настройки, а не позицию.
3. Вопрос: у главного такта 120 BPM, у одного из выходов деление на 2. Что на этом выходе?
   - Верно: один импульс на каждые два импульса мастера, то есть вдвое реже, как 60 BPM.
   - Неверно: импульсы вдвое чаще. Заблуждение: деление путают с умножением.
   - Неверно: те же импульсы, но вдвое тише. Заблуждение: деление меняет напряжение, а не частоту.

## Понятие

Идея без модуля: такт (клок, clock) — ровная последовательность коротких импульсов; каждый импульс говорит «сейчас». Темп — число таких импульсов в минуту (BPM). В герцах: частота = BPM / 60, поэтому 120 BPM = 2 Гц, 60 BPM = 1 Гц. В Rack такт — обычный сигнал, как гейт: 0 и 10 В ([vcv-voltage-standards](https://vcvrack.com/manual/VoltageStandards): гейт 10 В, триггер около 1 мс); аппаратный Eurorack обычно работает с 5 В, у Doepfer это видно из описания A-100 ([doepfer-tech](https://doepfer.de/a100_man/a100t_e.htm)), но для нас важен уровень не больше 10 В и чёткий фронт.

Деление такта: из главного такта получают более редкие импульсы (каждый второй, каждый четвёртый). Умножение даёт более частые. Reset — отдельный импульс «начни с начала»: после него все секвенсеры и делители снова стоят на первой доле. [ne-clocks](https://noiseengineering.us/blogs/loquelic-literitas-the-blog/getting-started-clocks/) описывает те же три роли: генератор такта, делители и сброс; одна из его мыслей: "Reset signals tell sequencers when to start over." ([ne-clocks](https://noiseengineering.us/blogs/loquelic-literitas-the-blog/getting-started-clocks/)).

Что показать (агент рисует): линию времени с делениями 1, 2, 3, 4 и на ней три строки импульсов: мастер (каждая доля), деление на 2 (каждая вторая), деление на 4 (каждая четвёртая); вертикальной чертой подписать момент Reset.

## Анатомия

Карточки: `Fundamental.LFO.md` (его уже знаем, берём только Square как такт), `Fundamental.SEQ3.md` (только блок такта: Tempo, Run, Reset, Clock), `ImpromptuModular.Clocked.md` (целиком). SEQ 3 подробно разберём в уроке 5.2. Не больше трёх терминов на шаг:

1. LFO как самый простой такт: выход Square (0 и 10 В при Offset = Unipolar), ручка Frequency. 2 Гц = 120 BPM. Термин: темп, BPM.
2. SEQ 3, блок такта: ручка Tempo (показание в bpm, 15…960), кнопка Run (переключает ход; новый SEQ 3 уже идёт, нажатие на идущем останавливает), кнопка Reset (следующий шаг — первый), вход Clock (кабель отключает внутренний такт), вход Reset, вход Run, кнопка Clock (один шаг вручную). Остальное (CV-ряды, Steps, триггеры) оставляем на урок 5.2. Термины: такт, сброс.
3. Clocked: ручка Master clock (BPM, 30…300, шаговая), три выхода Clock 1–3, ручки Clk 1 ratio, Clk 2 ratio, Clk 3 ratio (коэффициент ±96 в крайних положениях, 1 в центре), кнопки Run и Reset, выходы Master clock, Reset, Run. Термины: деление такта.
4. Ручки, которые пока только называем: Swing clk, Swing clk 1–3 (свинг), Pulse width clk и Pulse width clk 1–3 (длина импульса), Delay clk 1–3 (задержка выхода), Bpm mode prev и Bpm mode next (режим темпа), безымянный параметр (id 14, служебный), входы Unused 1–4 и BPM CV / Ext clock (внешний такт). К ним вернёмся в частях 8–9: «вернёмся в уроке 9.1».
5. Фраза из руководства ([impromptu-clocked](https://marcboule.github.io/ImpromptuModular/#clocked)): "The clock can also be synchronized to an external clock source." ([impromptu-clocked](https://marcboule.github.io/ImpromptuModular/#clocked)); поэтому у Clocked есть вход BPM CV / Ext clock. Пока без кабеля.

## Демо

Агент строит демо в своём ряду; ученик смотрит. Перед первым звуком звук не нужен: всё идёт на Scope, Audio не задействуем.

Модули: Fundamental/LFO, Fundamental/Scope, Fundamental/SEQ3, ImpromptuModular/Clocked.

Шаг A (LFO как такт, 120 BPM):

1. LFO `Square` → Scope `Ch 1`.
2. LFO Frequency = 2 (raw 1; показание «2» Гц), Offset = Unipolar. Scope Time подобрать так, чтобы на экране было 3–4 импульса (ориентир: показание около 500, единицу уточнить по снимку).
3. Спросить ученика: сколько импульсов в секунду? (Должно быть два.) Поднять Frequency до 4 (240 BPM) и спросить, как поменялась картинка.

Шаг B (внутренний такт SEQ 3):

4. SEQ 3: Tempo = 120 (raw 1), Run не трогать (новый SEQ 3 уже идёт), Steps = 2 (raw 2), `Step 1 trigger` = 1, `Step 2 trigger` = 0. Кабель SEQ 3 `Trigger` → Scope `Ch 2` (Ch 1 оставить от LFO для сравнения).
5. Агент читает `vcvrack_get_module` для SEQ 3: у выхода `Trigger` напряжение прыгает 0 → 10 В примерно каждую секунду (два шага по 0,5 с, триггер только на первом). Спросить ученика: почему не два импульса в секунду, ведь Tempo = 120? (Потому что триггер включён только на одном из двух шагов: деление на 2.)
6. Нажать Reset (raw 1, затем 0): картинка «прыгает» к началу цикла. Это и есть сброс.

Шаг C (Clocked, мастер и три деления):

7. Clocked: Master clock = 120, Run не трогать (новый Clocked уже идёт; кнопка Run переключает ход), Clk 1 ratio = 0 (показание 1), Clk 2 ratio = 1 (raw), Clk 3 ratio = −1 (raw). Прочитать displayValue после записи и показать ученику, как это выглядит на панели; какая сторона ручки делит и какая умножает, проверить вручную по Scope: ученик сам видит, на каком выходе импульсов больше.
8. Кабели: Clocked `Master clock` → Scope `Ch 1`; Clocked `Clock 2` → Scope `Ch 2`; затем переставить кабель Ch 2 с `Clock 2` на `Clock 3`. Вопрос ученику: какой из выходов вдвое реже мастера, а какой вдвое чаще?
9. Нажать Reset у Clocked: оба выхода стартуют от общей первой доли.

В конце агент удаляет свои модули и кабели.

## Покрути сам

1. Clocked Master clock от 60 до 180: на Scope импульсы теснее; на слух (если подключить звук к любому тактируемому модулю) метроном быстрее. Темп меняют только эту ручку: деления подстраиваются сами.
2. Clk 2 ratio в обе стороны: на одной стороне выход реже мастера, на другой чаще; запомни, какая сторона какая.
3. Pulse width clk 2: импульсы на Scope становятся шире или уже; темп не меняется.
4. Нажми Reset в разные моменты: какие выходы после этого снова совпадают с мастером?
5. SEQ 3: Tempo от 60 до 240 при идущем секвенсоре (кабель в Clock не вставлен): шаги ускоряются. Вставь кабель в Clock: ручка Tempo перестала что-либо менять.

## Практикум

Ученик собирает сам, агент ничего не трогает: Clocked, два Scope. Master clock между 80 и 140 BPM, Clocked идёт (новый Clocked уже запущен). Master clock → Ch 1 первого Scope, Clock 1 → Ch 2 того же Scope, Clock 2 → Ch 1 второго Scope, Clock 3 → Ch 2 второго Scope. Деления выставить так: Clock 1 — в такт мастеру (показание 1), Clock 2 — вдвое реже, Clock 3 — вчетверо реже. На Scope должно быть видно, что импульсы на Clock 2 и Clock 3 реже мастерских. Подсказки даются только через результат проверки.

## Проверка

Файл `checks/p5-01-clock-tempo.json`. Что проверяет: Clocked и два Scope; четыре кабеля (`Master clock` → Ch 1 первого Scope, `Clock 1` → Ch 2 первого, `Clock 2` → Ch 1 второго, `Clock 3` → Ch 2 второго); Master clock между 80 и 140; на выходе Master clock есть импульсы выше 5 В (для этого Clocked должен идти). Проверка не смотрит на коэффициенты делений: их агент читает сам через `vcvrack_get_params` и комментирует после проверки (Clock 2 и Clock 3 должны показывать разные значения, не равные 1). Если у ученика уже был Clocked, проверка найдёт любой.

Лесенка подсказок (вопрос, место, ответ):

- Кабели 1–4: «Что из Clocked не видно на Scope?» → «Четыре выхода справа: Master clock и Clock 1–3» → «каждый выход в свой вход Ch 1 или Ch 2».
- Темп вне 80–140: «Сколько битов в минуту сейчас?» → «Ручка Master clock» → «поставь от 80 до 140».
- Нет импульсов: «Тишина на Scope?» → «Идёт ли Clocked?» → «Кнопка Run у Clocked: новый уже идёт, нажатие на идущем останавливает» → «прочитай выход и включи Run, только если такт стоит».
- После проверки, по коэффициентам: «Все ли три деления разные?» → «Ручки Clk 2 ratio и Clk 3 ratio» → «Clock 2 вдвое реже, Clock 3 вчетверо реже».

## Слом

В демо-патче агента (Clocked, Master clock = 120, Run = 1, Clock 2 на Scope Ch 2): нажать Run (он переключает ход: на идущем Clocked это остановка). Ученик находит на Scope: линия легла на ноль, все импульсы пропали, хотя кабели и ручки на месте. Ответ: без Run такт стоит. Агент снова нажимает Run (читает выходы: Run переключает ход, так что нажимает только на остановленном) и удаляет демо. Для SEQ 3 то же правило: остановлен — шаги не идут.
