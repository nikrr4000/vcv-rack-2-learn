# MCP Server

## Что делает

Поднимает на твоём компьютере локальный HTTP-сервер, через который программа-помощник (агент) читает патч и вносит правки в Rack по протоколу MCP. В цепи звука его нет: это служебный модуль, не обрабатывающий сигналов.

## Ручки и переключатели

Снимок взят с модуля, уже стоявшего в патче владельца, параметры не двигали. Поэтому `displayValue` на концах и в середине хода не снимались: в таблице только значение на момент снимка (`displayDefault`).

| Параметр | id | min / max | displayValue min / mid / max | Что слышно |
| --- | --- | --- | --- | --- |
| HTTP Port | 0 | 2000 / 9999 | не снимались; на момент снимка 2600 (по умолчанию 2600), целые числа | Ничего: номер порта, на котором слушает сервер; курс ожидает 2600 |
| Enable HTTP Server | 1 | 0 / 1 | не снимались; на момент снимка 1 (включено), целые значения 0 и 1 | Ничего: включает и выключает сервер; при 0 агент Rack не видит |

Замечание о значении по умолчанию: в конфигурации плагина оно 0 (выключено), а `displayDefault` в снимке показывает 1, потому что модуль читали на включённом сервере. Положение переключателя после добавления нового модуля: проверить вручную.

## Входы и выходы

Входов нет. Один выход.

| Порт | Тип сигнала | Диапазон и нормализация |
| --- | --- | --- |
| Server heartbeat | служебный сигнал (не аудио) | назначение и диапазон напряжения: проверить вручную; к Audio его подключать не нужно |

## Контекстное меню

Общие пункты меню модуля (Plugin, Preset, Duplicate, Delete, Bypass, Disconnect cables): проверить вручную. Особые пункты MCP Server (если есть): проверить вручную.

## Полифония

Не применимо: звука нет, выход служебный.

## Типовые применения

- Включить обмен с агентом: поставить порт 2600 и включить `Enable HTTP Server` (урок 0.4).
- Дать Atlas читать патч для проверки практикума кнопкой «Проверить».
- Дать агенту строить демо в своей строке и показывать значения ручек и напряжения на подключённых выходах.

## Типовые ошибки

- Забыть включить `Enable HTTP Server`: агент не видит Rack, Atlas пишет «не отвечает».
- Поставить порт, который занят другой программой, или не тот, что ждёт курс (2600).
- Держать открытым меню или диалог в Rack: запрос агента не пройдёт по времени, пока меню не закрыто.
- Ждать, что агент сохранит или загрузит патч или настроит Audio: таких инструментов в плагине нет.
- Поставить два MCP Server в один патч: возможен конфликт портов (проверить вручную).
