# Random

## Что делает

Генератор случайного CV: по каждому такту (внутреннему или внешнему) с заданной вероятностью берёт новое случайное значение и отдаёт его на четырёх выходах, которые по-разному «подъезжают» к новому значению. Стоит в пути управления рядом с LFO; его выходы идут на высоту, срез, PWM. Основной урок — 4.4.

## Ручки и переключатели

| Метка (name) | id | min / max | displayValue: min / середина / max | Что слышно и видно при вращении |
| --- | --- | --- | --- | --- |
| Internal trigger rate | 0 | -8.965784 / 10.965784 | 0.002 / 2 / 2000 Гц | Частота внутреннего такта. По умолчанию (сырое 1) 2 Гц: два шанса на новое значение в секунду. Шкала экспоненциальная. Игнорируется, если подключён вход `Trigger`. |
| Shape | 1 | 0 / 1 | 0 / 50 / 100 % | Как выходы идут к новому значению. При 0 % все выходы прыгают сразу; при 100 % `Linear` тянется весь такт, а `Stepped` делает до 16 ступеней. По умолчанию 100 %. |
| Offset | 2 | 0 / 1 | Bipolar / Unipolar / Unipolar | Диапазон: Bipolar (сырое 0, по умолчанию) −5…+5 В, Unipolar (сырое 1) 0…10 В. |
| (без подписи, id 3) | 3 | 0 / 1 | 0 / 0.5 / 1 | Скрытый унаследованный параметр, не подписан. Не трогать. |
| Trigger probability | 4 | 0 / 1 | 0 / 50 / 100 % | Вероятность, что на такте возьмётся новое значение. 100 % — на каждом такте; 0 % — никогда. Когда значение взято, на выходе `Trigger` идёт импульс. |
| Random spread | 5 | 0 / 1 | 0 / 50 / 100 % | Насколько новое значение независимо от предыдущего. 100 % — полностью случайное; 0 % — значение не меняется; между ними — значения случайны, но остаются рядом с прежним. (Это не размах напряжения, а «прыгучесть».) |
| Internal trigger rate CV | 6 | -1 / 1 | -100 / 0 / 100 % | Глубина входа `Internal trigger rate`: 1 В на октаву скорости при 100 %. |
| Shape CV | 7 | -1 / 1 | -100 / 0 / 100 % | Глубина входа `Shape`. |
| Trigger probability CV | 8 | -1 / 1 | -100 / 0 / 100 % | Глубина входа `Trigger probability`. |
| Random spread CV | 9 | -1 / 1 | -100 / 0 / 100 % | Глубина входа `Random spread`. |

## Входы и выходы

| Имя (name) | Вход / выход | Тип сигнала | Диапазон | Нормализация и пр. |
| --- | --- | --- | --- | --- |
| Internal trigger rate | вход | CV | ±5 В | Скорость внутреннего такта, масштаб — ручка Internal trigger rate CV. |
| Shape | вход | CV | 0…10 В или ±5 В | Масштаб — ручка Shape CV. |
| Trigger | вход | триггер | положительный фронт | Если подключён, внутренний такт отключается: новое значение берётся только по приходящим триггерам (вероятность всё равно работает). |
| External | вход | CV | любой | Если подключён, на каждом такте вместо случайного значения берётся напряжение с этого входа, то есть модуль работает как выборка-хранение; Random spread тогда не влияет. |
| Trigger probability | вход | CV | 0…10 В | Масштаб — ручка Trigger probability CV. |
| Random spread | вход | CV | 0…10 В | Масштаб — ручка Random spread CV. |
| Stepped | выход | CV | Bipolar ±5 В / Unipolar 0…10 В (проверить на Scope) | Движется ступенями; при Shape 0 % — чистая выборка-хранение. |
| Linear | выход | CV | то же | Идёт к новому значению по прямой. |
| Smooth | выход | CV | то же | Идёт к новому значению плавно, по синусной кривой. |
| Exponential | выход | CV | то же | Идёт экспоненциально; при Shape 100 % становится прямой. |
| Trigger | выход | триггер | 10 В | Импульс в момент, когда взято новое значение. |

Выход сообщает напряжение по REST только пока в него воткнут кабель — важно для проб в проверках.

## Полифония

Модуль полифонический; `External` с версии 2.6.3 принимает полифонический сигнал (по руководству). Остальное проверить вручную. Для курса достаточно монорежима.

## Типовые применения

1. Дрожащий тембр: `Smooth` в `Frequency` у VCF (урок 4.4).
2. Случайная высота: `Stepped` через Rescale в `1V/octave pitch` (урок 4.4; в части 5 — с квантайзером).
3. Выборка-хранение из внешнего сигнала: LFO или шум в `External`, такт в `Trigger`.
4. Случайные гейты: выход `Trigger` с вероятностью меньше 100 % — рваный ритм.

## Типовые ошибки

1. Подали `Stepped` в 1V/octave без масштабирования: ±5 В — это ±5 октав, мелодия превращается в хаос.
2. Путают Random spread с размахом напряжения: ручка управляет зависимостью от прошлого значения.
3. Крутят Internal trigger rate при подключённом `Trigger`: ручка игнорируется.
4. Ждут новых значений при Trigger probability 0 %.
5. Не видят движения: Shape 100 % и низкая частота — выходы тянутся целый такт, а `Stepped` почти не отличим от `Linear` на глаз.
