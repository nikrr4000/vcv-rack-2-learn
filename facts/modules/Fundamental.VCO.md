# VCO

## Что делает

VCO (Voltage-controlled oscillator, генератор, управляемый напряжением) создаёт периодический звуковой сигнал четырёх форм — синус, треугольник, пила, прямоугольник — на частоте, которую задают ручка Frequency и напряжение на входе `1V/octave pitch`. Это начало типичного голоса: VCO даёт сырой звук, дальше его обрабатывают фильтр (VCF), усилитель (VCA) и огибающая.

## Ручки и переключатели

Частота в таблице — значение `displayValue` в герцах. Значения `displayValue` взяты из снапшота: при ручке в минимуме, в середине диапазона и в максимуме.

| Метка (name) | id | min / max | displayValue: min / середина / max | Что слышно и видно при вращении |
| --- | --- | --- | --- | --- |
| (без подписи, id 0) | 0 | 0 / 1 | 0 / 0.5 / 1 | Скрытый унаследованный параметр, на панели Rack 2.6 не подписан. Не трогать; в уроках его нет. |
| Sync mode | 1 | 0 / 1 | Soft / Hard / Hard | Переключатель режима синхронизации (по умолчанию Hard). Hard: по фронту на входе `Sync` фаза обнуляется — резкий «рваный» тембр. Soft: по фронту волна разворачивается — мягче. Эффект слышен только когда в `Sync` пришёл кабель. Урок 2.2. |
| Frequency | 2 | -54 / 54 | 11.562 / 261.63 / 5919.9 Гц | Основная частота. Если на `1V/octave pitch` приходит кабель, напряжение прибавляется к положению ручки. |
| (без подписи, id 3) | 3 | 0 / 1 | 0 / 0.5 / 1 | Скрытый унаследованный параметр, не подписан. Не трогать. |

| Pulse width | 5 | 0.01 / 0.99 | 1 / 50 / 99 % | Ширина импульса прямоугольника на выходе `Square`: 50 % — ровный меандр, к краям звук тоньше и «носовее». Остальные формы не меняются. Урок 2.2. |

## Входы и выходы

| Имя (name) | Вход / выход | Тип сигнала | Диапазон | Нормализация и пр. |
| --- | --- | --- | --- | --- |
| 1V/octave pitch | вход | 1V/oct (CV высоты) | обычно −5…+5 В вокруг C4; 0 В = C4 | Если не подключён, высота определяется только ручкой Frequency. Полифонический: число каналов определяет число голосов. |
| Frequency modulation | вход | аудио или CV | ±5 В (сигнал модулятора) | Масштабируется ручкой Frequency modulation; при 0 % не влияет. Не нормализован. |
| Sync | вход | фронт (гейт/триггер или аудио) | положительный фронт выше нескольких вольт | По фронту ведомый VCO перезапускает цикл; режим — переключатель Sync mode. Не нормализован. |
| Pulse width modulation | вход | CV | ±5 В | Складывается с ручкой Pulse width после масштаба ручкой Pulse width modulation. Не нормализован. |
| Sine | выход | аудио | около ±5 В | Синус: только основная частота, без гармоник. |
| Triangle | выход | аудио | около ±5 В | Треугольник: нечётные гармоники, быстро затухающие. |
| Sawtooth | выход | аудио | около ±5 В | Пила: все гармоники, самый «густой» исходник для вычитающего синтеза. |
| Square | выход | аудио | около ±5 В | Прямоугольник: нечётные гармоники, ширина по Pulse width и входу PWM. |

Уровни в таблице — типовой стандарт аудио ±5 В (источник vcv-voltage-standards); точный размах каждого выхода проверить на Scope или через `get_module`.

## Контекстное меню

Снапшот пунктов меню не содержит. Всё ниже — проверить вручную.

- Общие пункты Rack для любого модуля: Initialize (вернуть ручки к умолчанию), Randomize, Copy/Paste preset, Disable, Duplicate, Delete. Проверить вручную.
- В Fundamental VCO могут быть дополнительные пункты поведения (режим «аналоговый» или «цифровой», ограничения частоты, синхронизация); состав меню зависит от версии 2.6.4. Проверить вручную по правому клику.
- Переключатели Sync mode и FM mode продублированы на панели — менять их можно и там, и (если есть) в меню. Проверить вручную.

## Полифония

Модуль полифонический: число каналов выходов равно числу каналов на входе `1V/octave pitch` (до 16). Если на высоту пришёл монокабель, выходы монофонические. Одноканальные кабели на `Frequency modulation`, `Sync` и `Pulse width modulation` действуют на все голоса сразу; полифонические — по каналам.

## Типовые применения

1. Источник звука голоса: Sawtooth или Square → VCF → VCA → Audio (урок 3.5).
2. Живой прямоугольник: LFO Triangle в `Pulse width modulation` (урок 2.2).
3. Жёсткая синхронизация: Square первого VCO в `Sync` второго, второй настроен выше (урок 2.2).
4. Два генератора с расстройкой — хор и густая пила (урок 2.3).
5. Басовая синусоида или основа для барабана: Sine на низкой частоте (часть 8).

## Типовые ошибки

1. Ждут звука с VCO без кабеля в Audio: ни один выход не подключён — тишина.
2. Путают Frequency (ручка в Гц/полутонах) и `1V/octave pitch` (вход напряжения): ручка и CV складываются.
3. Крутят Pulse width и слушают Sine — ширина влияет только на `Square`.
4. Включают Sync mode, но не подают кабель в `Sync` — ничего не происходит.
5. Ставят Frequency modulation в 100 % при режиме Linear с громким модулятором и получают шум вместо высоты.

## Аналог в Eurorack

Классический аналоговый VCO с четырьмя выходами и входом 1V/oct (например, универсальные генераторы формы), но с цифровым ядром. Прямого модуля-двойника нет: многие функции здесь собраны в одном модуле.
