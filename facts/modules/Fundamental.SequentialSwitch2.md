# Sequential Switch 4 to 1

## Что делает

Собирает на один выход один из четырёх входов, выбирая следующий по каждому такту; ставится перед VCO или VCF, чтобы по очереди брать значения из четырёх источников.

## Ручки и переключатели

| Подпись | id | Диапазон (raw) | Показание: min / середина / max | Что слышно или видно при вращении |
| --- | --- | --- | --- | --- |
| Steps | 0 | 0 … 2 | 2 / 3 / 4 | Сколько каналов участвует в цикле: 2, 3 или 4. Ручка шаговая: показания «2 / 3 / 4». После последнего канала переключатель возвращается на первый. |

## Входы и выходы

| Направление | Имя | Тип сигнала | Ожидаемый диапазон | Нормализация и примечания |
| --- | --- | --- | --- | --- |
| вход | Clock | тактовый импульс | 10 В, фронт | Каждый нарастающий фронт переключает на следующий канал. |
| вход | Reset | триггер | 10 В, фронт | Возвращает переключатель на первый канал. |
| вход | Channel 1 | любой (аудио, CV, гейт) | ±10 В | Один из четырёх источников; выход «Main» получает тот, чей канал сейчас активен. |
| вход | Channel 2 | любой (аудио, CV, гейт) | ±10 В | Один из четырёх источников; выход «Main» получает тот, чей канал сейчас активен. |
| вход | Channel 3 | любой (аудио, CV, гейт) | ±10 В | Один из четырёх источников; выход «Main» получает тот, чей канал сейчас активен. |
| вход | Channel 4 | любой (аудио, CV, гейт) | ±10 В | Один из четырёх источников; выход «Main» получает тот, чей канал сейчас активен. |
| выход | Main | любой (как на входе) | как на входе | Сигнал активного канала. |

## Полифония

Библиотека помечает модуль «Polyphonic»: сигнал Main сохраняет число каналов (проверить вручную).

## Типовые применения

1. Мелодия из четырёх источников по очереди: Random Values → Channel 1–4 → Main → VCO (урок 5.5).
2. Переключатель между четырьмя источниками CV: разные «характеры» одной ноты.
3. Выбор между четырьмя ритмами или огибающими по такту.
4. Режим Steps = 2: два источника, чередующиеся каждый такт.
5. Расширение секвенсора: добавить ещё CV-рядов.

## Типовые ошибки

1. Кабель подан в Main как выход: у 4→1 один выход Main, четыре входа Channel 1–4.
2. Нет кабеля в Clock: канал не меняется.
3. Steps = 4, но заняты не все каналы: на пустом канале 0 В, нота C4.
4. Reset не подан: фраза начинается с произвольного места.
5. Ждут сглаженного перехода между каналами: переключение мгновенное, это ступенька.
